# Project Statement

## Project Title
Smart Hand Gesture Recognition System

## Problem Statement
Design and implement a Computer Vision system that can recognize predefined human hand gestures from a live camera stream and display the recognized gesture to the user.

## Scope
The project covers webcam video capture, hand landmark detection, feature extraction, gesture classification and real-time visualization. The initial version focuses on five gestures: Open Palm, Fist, Thumbs Up, Victory and OK.

## Target Users
- Students learning Computer Vision
- Users interested in vision-based human-computer interaction
- Demonstration and educational use

## High-Level Features
- Real-time webcam input
- Hand landmark visualization
- Feature extraction
- Gesture classification
- Confidence display
- Modular implementation
